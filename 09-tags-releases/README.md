# 09 — Tags and releases

## Goal
Mark important versions and understand lightweight versus annotated tags.

## Exercises
1. Create a lightweight tag on a practice commit.
2. Create an annotated tag such as `v0.1.0`.
3. Inspect tags with `git tag -n` and `git show v0.1.0`.
4. Push a tag to the remote.
5. Delete a local practice tag and explain how remote tag deletion differs.
6. Draft release notes for a pretend version.

## Commands
```bash
git tag
git tag -a v0.1.0 -m "First practice release"
git show v0.1.0
git push origin v0.1.0
```
